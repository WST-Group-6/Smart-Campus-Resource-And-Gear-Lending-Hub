# Smart Campus Resource & Gear Lending Hub

## Project Overview

The Smart Campus Resource & Gear Lending Hub is a web-based platform that allows university students to share, borrow, and lend useful academic and personal resources.

## Main Features

- User registration and login
- Browse available items
- View item details
- Submit borrowing requests
- Approve or reject borrowing requests
- Track borrowed items and returns
- View borrowing history
- Admin dashboard

## Technologies

- Frontend: HTML, CSS, JavaScript
- Backend: Java
- Database: MySQL
- Database Connectivity: JDBC
- Version Control: Git and GitHub

## Project Structure

- `frontend/` – Website interface
- `backend/` – Java backend application
- `database/` – Database scripts
- `docs/` – Project documentation
